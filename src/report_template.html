Research pipeline · evidence before verdicts

App toolkit evidence audit

What the run establishes

No independent accuracy percentage is claimed without labeled ground truth. Source retrieval, source support and real credential usability are different measurements.

The pipeline

01 / CollectRead supplied primary documentation URLs. Save dated, hashed public snapshots.
02 / ExtractIdentify candidate auth, access, API and MCP statements. Keep evidence alongside every signal.
03 / ChallengeFlag contradictory or missing coverage. Contextual review decides scope, not keyword counts.
04 / VerifyLog corrections and separate agent checks from completed human checks.

Findings and evidence

Reproduce the run

python -m unittest discover -s tests -v
python src/audit.py --input data/apps.json --expected-count 100 --output output
python src/audit.py --input data/apps.json --expected-count 100 --output output --offline

The official input list is mandatory. No replacement apps are silently generated. Fresh evidence requires an explicit refresh. No paid accounts, production API calls or credentials are used.
